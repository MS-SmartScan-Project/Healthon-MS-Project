Technology

From MRI image to clinical insight

A low-cost Raspberry Pi device that brings AI screening to clinics with limited access to MS specialists.

  1. 01Capture

    Raspberry Pi Camera Module v2 or direct image upload.

  2. 02Enhance

    Grayscale conversion and CLAHE contrast normalization (OpenCV).

  3. 03Detect

    YOLO11n lesion detector with test-time augmentation, 640 px input.

  4. 04Report

    Finding, confidence, flagged regions, and next clinical step — saved to the record.

AI model

YOLO11n fine-tuned on labeled MRI slices (100 epochs, 640 px). Metrics are from the model's validation split.

Device

  • Raspberry Pi 5 (4 GB) with Camera Module v2 and touch display
  • Runs fully offline — no cloud, no internet required after setup
  • Low-cost, portable hardware suited to clinics and screening centers
  • Same software runs on a Windows workstation

Privacy & safety

  • Server accepts connections from this device only (localhost)
  • Required patient identifiers; one medical number per patient
  • Duplicate MRI protection via image fingerprints (SHA-256)
  • CSRF protection, rate limiting, and an audit log of every action
  • Automatic daily database backups (last 7 kept)
