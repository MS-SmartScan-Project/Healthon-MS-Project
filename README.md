# MS SmartScan — موقع العرض (هيلثون)

موقع يعرض فكرة الجهاز، ويشغّل نموذج الذكاء الاصطناعي `best.pt` مباشرة على صور الرنين المغناطيسي.
**بدون PHP وبدون XAMPP وبدون MySQL**، ويحتاج بايثون فقط.

## التشغيل

| الجهاز | الطريقة |
|---|---|
| **ويندوز** | دبل كليك على **`START-Windows.bat`** |
| **Raspberry Pi** | دبل كليك على **`start-raspberry.sh`** ثم **Execute** (أو اكتبي في الطرفية `./start-raspberry.sh`) |

وبس ✅
- **أول مرة:** يثبّت مكتبات الذكاء الاصطناعي تلقائياً، وياخذ كم دقيقة ويحتاج إنترنت.
- **بعدها:** يفتح المتصفح لحاله على **http://localhost:8000**.
- انتظري لين تصير الشارة فوق 🟢 **النموذج جاهز**.
- **لإيقاف الموقع:** سكّري النافذة السوداء.

الشيء الوحيد اللي لازم يكون مثبّت هو **Python**. إذا مو موجود، ملف التشغيل يفتح لك صفحة تنزيله.

## طريقة الفحص
1. انزلي لقسم **الفحص**.
2. اختاري **الكاميرا** (ثم «تشغيل الكاميرا») أو **رفع صورة**.
3. اكتبي اسم المريض ورقمه إذا تبين (اختياري).
4. اضغطي **التقاط وتحليل**.
5. تظهر النتيجة، وتظهر مربعات حول البؤر على الصورة، ويُحفظ الفحص في **السجل**.

## الملفات
| الملف | الوظيفة |
|---|---|
| `server.py` | السيرفر: يعرض الموقع، ويستقبل الصور، ويحفظ السجل |
| `detector.py` | يحمّل `best.pt` مرة وحدة، ويحلل بنفس خطوات `predict.py` |
| `best.pt` | نموذج YOLO11 المدرَّب |
| `predict.py` | السكربت الأصلي (بدون تعديل، للمرجع) |
| `START-Windows.bat` · `start-raspberry.sh` | ملفات التشغيل |
| `static/` | الواجهة: `index.html` و`style.css` و`app.js` |
| `data/` | يُنشأ تلقائياً: قاعدة SQLite والصور |

## كيف يحلل الموقع الصورة؟
نفس خطوات `predict.py` بالضبط:
1. تحويل الصورة للرمادي وتحسين التباين بخوارزمية **CLAHE** (clipLimit=3.0, tile 8×8).
2. تشغيل `best.pt` بحد ثقة `conf=0.05`.
3. **إذا وُجدت بؤر:** النتيجة `Infected` مع أعلى نسبة ثقة. **وإلا:** النتيجة `Healthy` بنسبة 100.

وتُطبَّق نفس قاعدة النظام الأصلي: نتيجة `Infected` بثقة أقل من **70%** تُعرض سليمة. تقدرين تغيّرين الرقم من `MIN_CONFIDENCE` في `server.py`.

## حل المشاكل
- **الشارة حمراء «النموذج غير محمّل»:** تأكدي إن الإنترنت شغّال أول مرة، وسكّري الموقع وشغّليه من جديد.
- **الكاميرا ما تشتغل:** افتحي الموقع على `localhost` واسمحي للمتصفح باستخدام الكاميرا، أو استخدمي «رفع صورة».
- **المنفذ 8000 مشغول:** السيرفر يجرب 8001 و8002… تلقائياً، والرابط يطلع لك في الطرفية.
